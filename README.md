## 📌 Sobre o projeto

Este é o primeiro projeto da minha sequência de estudos práticos em desenvolvimento Front-end.

O objetivo foi praticar conceitos fundamentais de HTML e CSS, incluindo:

- Estrutura semântica de uma página
- Organização de elementos
- Flexbox
- Espaçamento e alinhamento
- Cores e tipografia
- Bordas e sombras
- Efeitos de hover
- Responsividade

## 🎯 Objetivo

Desenvolver uma interface simples de cartão de perfil utilizando apenas HTML e CSS, sem frameworks ou bibliotecas externas.
